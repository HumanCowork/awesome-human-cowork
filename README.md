## 🤝 ¿Cómo Contribuir?

Este repositorio crece gracias a la comunidad. Si tenés un prompt que te ahorró horas, una skill que armaste para tu stack, o un flujo de N8N que querés compartir:

1. Lee nuestra **[Guía de Contribución](CONTRIBUTING.md)**.
2. Hacé un fork del repositorio.
3. Creá una rama (`feature/mi-aporte`).
4. Abrí un **Pull Request**. Una vez revisado se mergea para todos.

> 🤖 **¿Contribuís mediante un agente de IA?** Compartile nuestro archivo **[AGENTS.md](AGENTS.md)** para que aplique automáticamente las reglas de introspección dinámica, adaptación de tablas y formato de PRs sin fricciones.
