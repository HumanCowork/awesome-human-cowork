# ⚙️ Automatizaciones & Workflows

Repositorio de flujos automáticos listos para desplegar en tu propia infraestructura (N8N, Make o scripts personalizados).

## 🚀 Flujos Destacados

1. **Scraping & Lead Generation con N8N:** Automatización de búsqueda y enriquecimiento de prospectos para agencias de software.
2. **Integración Telegram / Discord / WhatsApp:** Notificaciones automáticas de eventos y alertas.
3. **Resúmenes automáticos con IA:** Procesamiento de transcripciones de reuniones y minutas automáticas.

---

## 📥 Cómo importar un flujo en N8N

1. Descargá el archivo `.json` del workflow que quieras.
2. Abrí tu instancia de N8N.
3. En el menú superior, hacé clic en **Import from File** (o arrastrá el `.json` al lienzo).
4. Configurá tus credenciales locales (OpenAI, Anthropic, Supabase, etc.).
