## 💡 Filosofía del Banco de Prompts
Un buen prompt no es magia ni adivinación: es **contexto claro, restricciones precisas y contratos de salida estructurados**. 

Evitamos los prompts genéricos de relleno ("actúa como un experto"). Cada recurso en esta biblioteca debe resolver un dolor de trinchera y exigir código o entregables verificables.
